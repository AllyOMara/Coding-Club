***<h1 style="text-align:center;">Welcome to Pong, recreated in Pygame</p>***
<br>

So far the following has been done:
- Two Players have been created
- The players can move
- The players are given a boundary
- A ball has been added
- The ball can move within the screen
- Make the ball interact with the player
- Make the ball interact with the boundary behind the player
- Scoring system
<br><br>

Some extra completed ideas:
- Pressing esc or the top right close button (x) closes the game
- The ball initially randomly moves to either the left or right side
- Game requires the player to press a key to start
- Fullscreen can be toggled using left ctrl
- Text has been added to indicate the preceding two points are available
